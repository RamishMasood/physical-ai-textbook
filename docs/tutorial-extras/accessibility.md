# Accessibility

This textbook is designed to be accessible to all learners. This page explains the accessibility features and guidelines.

## Web Content Accessibility Guidelines (WCAG)

The textbook follows WCAG 2.1 AA standards to ensure content is:

- **Perceivable**: Information is presented in ways that users can perceive
- **Operable**: Interface components are operable by all users
- **Understandable**: Information and UI operation are understandable
- **Robust**: Content is robust enough to work with various assistive technologies

## Color and Contrast

All text maintains a contrast ratio of at least 4.5:1 against its background, meeting WCAG AA standards. The primary color scheme was chosen to provide adequate contrast for readability.

## Keyboard Navigation

The site supports full keyboard navigation:
- Use `Tab` to navigate between interactive elements
- Use `Enter` or `Space` to activate links and buttons
- Use arrow keys to navigate within components like tabs

## Screen Reader Support

All content is structured with proper heading hierarchies (H1, H2, H3, etc.) to facilitate navigation with screen readers. Images include descriptive alt text, and complex diagrams have text alternatives.

## Content Accessibility

### Text Alternatives

- All images include descriptive alt text
- Complex diagrams are accompanied by detailed descriptions
- Videos include captions and transcripts when applicable

### Clear Structure

- Consistent heading hierarchy
- Descriptive link text that indicates purpose
- Clear focus indicators for interactive elements

### Adaptable Content

- Responsive design works on various screen sizes
- Content can be zoomed to 200% without loss of functionality
- Text scales appropriately with browser settings

## Math and Code Accessibility

Mathematical content is presented using clear notation and includes verbal descriptions where appropriate. Code examples include explanations to help users understand the concepts without relying solely on visual formatting.

## User Preferences

The site respects user preferences for:
- Reduced motion (prefers-reduced-motion media query)
- Color scheme (light/dark mode toggle)
- Text size (responsive design adapts to browser text sizing)

## Testing for Accessibility

Regular accessibility testing is performed using:
- Automated tools like axe-core
- Manual keyboard navigation testing
- Screen reader testing with tools like NVDA and JAWS
- Color contrast analysis
