## Tip Admonitions

Use tip admonitions for helpful suggestions:

:::tip
When tuning PID controllers, start with small values for the integral and derivative gains, then gradually increase them while monitoring system response.
:::

:::tip[Best Practice]
Always implement safety limits when controlling real robotic hardware to prevent damage.
:::

## Warning Admonitions

Use warning admonitions for important cautions:

:::warning
Running control algorithms on real hardware without proper safety measures can result in equipment damage or injury.
:::

:::warning[Critical Consideration]
Always verify that your robot's center of mass remains within its support polygon when planning movements.
:::

## Danger Admonitions

Use danger admonitions for critical warnings:

:::danger
Never exceed the maximum joint velocity or torque limits specified in the robot's documentation.
:::

:::danger[Critical Safety]
Ensure emergency stop procedures are in place before running any control algorithms on physical robots.
:::
