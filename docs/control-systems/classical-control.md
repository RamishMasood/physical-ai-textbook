# Classical Control

This section covers classical control theory concepts.

## Transfer Functions

A transfer function represents the relationship between the input and output of a system in the frequency domain.

```
G(s) = Y(s)/U(s)
```

## PID Controllers

Proportional-Integral-Derivative (PID) controllers are widely used in control systems:

- **P (Proportional)**: Reduces steady-state error
- **I (Integral)**: Eliminates steady-state error
- **D (Derivative)**: Improves stability and response time

## Stability Analysis

Methods for analyzing system stability:

- Routh-Hurwitz criterion
- Root locus
- Bode plots
- Nyquist plots
